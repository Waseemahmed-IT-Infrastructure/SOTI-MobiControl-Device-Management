
# SOTI MobiControl Device Management

## Overview

This repository covers enterprise mobile device management using SOTI MobiControl.

It includes device enrollment, monitoring, application deployment, remote management and basic troubleshooting.

## Device Management

Common administration tasks include:

- Checking enrolled devices
- Reviewing device connectivity
- Monitoring device status
- Organizing devices into groups
- Reviewing device information
- Checking assigned configurations
- Investigating device issues

## Device Enrollment

A general enrollment process includes:

1. Prepare the device for enrollment.
2. Verify the required enrollment settings.
3. Connect the device to the network.
4. Follow the approved enrollment procedure.
5. Confirm that the device appears in SOTI MobiControl.
6. Verify the device group and assigned configuration.
7. Check device connectivity.

## Application Management

SOTI MobiControl can be used to manage applications on supported devices.

Common tasks include:

- Deploying approved applications
- Checking application installation status
- Reviewing application versions
- Updating applications
- Troubleshooting failed deployments

## Remote Device Management

Depending on the device platform, permissions and configuration, available tasks may include:

- Viewing device information
- Checking device connectivity
- Remote troubleshooting
- Reviewing device logs
- Sending supported management commands

## Device Troubleshooting

| Issue | What to Check |
|---|---|
| Device offline | Network connectivity and device status |
| Device not enrolled | Enrollment settings and connectivity |
| Application not installed | Deployment status and device compatibility |
| Configuration not applied | Device group and assigned profile |
| Device not communicating | Network, agent status and management connection |

## Basic Troubleshooting Process

1. Identify the affected device.
2. Review its status in SOTI MobiControl.
3. Check network connectivity.
4. Review assigned applications and configurations.
5. Check available logs and error messages.
6. Apply approved troubleshooting steps.
7. Verify that the device is working correctly.

## Best Practices

- Follow approved device enrollment procedures.
- Use the correct device groups and configurations.
- Verify application compatibility before deployment.
- Document changes and troubleshooting results.
- Avoid publishing device identifiers or company-specific settings.

## Note

This repository contains general technical documentation. No real device identifiers, internal server details or company configurations are included.
